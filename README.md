# TetherShare 🚀

**TetherShare** is a lightweight and powerful Android application that turns your device into a portable HTTP proxy server. It allows you to share your internet connection with other devices (laptops, phones, consoles) over a local network without requiring root access.

## ✨ Features

- **Portable Proxy Server**: Instantly host an HTTP proxy on any available port.
- **No Root Required**: Works on standard Android devices using high-performance socket bridging.
- **Real-time Monitoring**: 
    - Live bandwidth usage graph.
    - Active connection counter.
    - Session data usage tracking (MB/GB).
- **Proxy Authentication**: Secure your connection with multi-user support (Basic Auth).
- **Modern UI**: Clean, Jetpack Compose-based interface with Material 3 design.
- **Theme Support**: Includes Light, Dark, System Default, and AMOLED (True Black) modes.
- **Stability Focused**: Optimized for Android 12+ with robust socket handling and background persistence.
- **Multilingual**: Fully localized in English and Turkish.
- **Quick Settings Tile**: Toggle the proxy instantly from your Android notification shade.

## 🛠 How It Works

1. **Start the Proxy**: Enter a port (default: 8080) and tap "Start Proxy".
2. **Connect Clients**: Configure the proxy settings on your other devices using the IP addresses displayed in the app.
3. **Authenticate (Optional)**: If enabled in Settings, clients will be prompted for a username and password.
4. **Monitor**: Watch live traffic stats and connected device counts directly on the dashboard.

## 🔒 Security & Privacy

- **Local Only**: The proxy server operates within your local network.
- **Authentication**: Prevent unauthorized access by creating multiple user accounts in the app settings.
- **Battery Optimization**: Provides guidance on how to disable battery restrictions to ensure stable background service.

## 📥 Installation

1. Download the latest APK from the [Releases](https://github.com/psunyter/TetherShare/releases) page.
2. Enable "Install from Unknown Sources" in your Android settings.
3. Install and start sharing!
